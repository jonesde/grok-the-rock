# Plan: Voice pass on `mending-place.html`

## Goal

Reduce second-person address (`you` / `your` / etc.) where it isolates the reader, sounds instructional-at-a-distance, or risks feeling accusatory — so the guide walks *with* the reader without lecturing them.

## Voice rules (authoritative)

Apply in this order:

1. **Prefer impersonal structure** when the sentence works without `you` *or* `we`.
   - Bare imperative: “Choose one… Reduce… Notice…”
   - Passive / noun-led: “Protective limits are drawn from what is legitimately stewarded…”
   - Generic third person: “people”, “the injured party”, “a household”, “the body”
   - Rationale: less personal, less potentially triggering; avoids both lecture-`you` and forced-`we`.

2. **Use inclusive `we` / `our` only** when it truly means author + reader sharing the work, and does **not** force the author into a claim, decision, or situation that is not shared.
   - Good: shared practice, shared weather of ranking/repair, shared experiments framed as joint discipline.
   - Bad (royal / forced we): putting the author inside the reader’s household, partner, trauma state, property choices, or entitlements.

3. **Keep `you` / `your`** when the matter is a **personal decision** or **personal stake** — especially over one’s own body, dependents, property, stewardships, or what one makes and may open.
   - Canonical keep: Rule 7 title and framing **“Open what you make”** (and body language that is about the maker’s own work/property).
   - Also keep: protective limits over *your* body / *what is yours to tend* when rewriting to impersonal would blur that the line is personal, not collective ownership.

4. **Never change**
   - Scripture quotations
   - Quoted speech (good or bad examples)
   - Dialogue / parent / threat-mode **scripts** (the spoken lines)
   - Diagnostic questions already in first-person `I` / `my` (self-check form)

5. **Inclusive we ≠ royal we**  
   If “we” would claim the author is in the reader’s marriage, flooding, refusal dynamics, or property call, restructure impersonally or keep a careful `you` for that personal locus.

---

## Decision matrix (quick)

| Situation | Prefer |
|-----------|--------|
| General principle, diagnosis, community pattern | Impersonal |
| Shared practice the book models with the reader | Inclusive `we` (sparingly) |
| Personal property, making, body, stewarded charge, personal yes/no | Keep `you` / `your` |
| Quotes, scripts, scripture, example dialogue | Unchanged |
| Self-exam prompt | Keep `I` / `my` diagnostics; experiments → imperative or light `we` only if joint |

### B. Light inclusive `we` (only where shared and natural)

Use sparingly; Rule 5 already models this well. Good fits:

- Shared noticing of ranking weather (if impersonal feels cold)
- “How do we repair it?” already present — leave
- Closing maintenance that is clearly communal practice among people using the book **without** claiming the author’s household

If in doubt between `we` and impersonal → **impersonal**.

### C. Explicit keep-`you` zones (personal decision / property / body)

Do **not** convert these to `we`/`our`:

- **Open what you make** (title + personal open/share choices)
- Guarding **your** body, dependents, property, stewardships entrusted **to you**
- Standing **your** ground / what is **yours** to tend (personal locus of stand)
- “Tend what is entrusted to you” when it means personal charge
- Experiment items that are inherently private property/skill: prefer imperative first (“Choose one skill that can be safely shared…”); a single `you` is fine if impersonal is awkward

## Implementation steps

1. Work section-by-section through `mending-place.html` (intro → Part One → Rules → Parts Three–Six → glossary).
2. For each `you`/`your` hit:
   - Skip if in keep lists (quotes, scripts, scripture, Rule 7 personal-property, body/stewardship personal locus).
   - Else try impersonal restructure.
   - Else inclusive `we` only if clearly shared and not royal.
   - Else leave `you` if personal decision/stake.
3. Prefer minimal edits; no added commentary in the file.
4. Final grep: `\b(you|your|yours|yourself|yourselves)\b` — every remaining hit must justify under keep rules.
5. Spot-read opening, Rule 3 limits, Rule 5 (already `we`), Rule 7 (keep `you`), Rule 10, refusal section, “enough” close for consistency.
6. No other files unless requested.

## Success criteria

- Reader feels accompanied, not singled out or accused.
- Personal property and personal protective decisions still use clear `you` where needed (esp. Rule 7 and stand/limits).
- No royal-we that drafts the author into the reader’s life.
- Where neither person is needed, prose is calm and impersonal.
- Diagnostics stay `I`/`my`; experiments are mostly imperative/impersonal.
